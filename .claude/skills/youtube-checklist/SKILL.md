# YouTube 영상 → 사전점검 체크리스트 반영

사용자는 주로 **휴대폰(갤럭시)에서 음성 입력**으로 요청한다. 답은 짧고 쉬운 한국어로.

## 순서

1. **도구 준비**: `yt-dlp`가 없으면 `pip install -q yt-dlp`.
2. **영상 찾기** (검색어를 받았을 때):
   `python3 tools/yt_tool.py search "<검색어>" --n 25`
   - 조회수 순으로 나온다. 뉴스·단순 브이로그는 빼고 **해설형 영상**을 고른다.
   - 이미 반영한 영상은 `data/youtube_videos.tsv`에 있다. 겹치면 건너뛴다.
3. **자막 받기**: `python3 tools/yt_tool.py fetch <id 또는 URL> ...`
   - 자막은 `tools/transcripts/<id>.txt`(git에 올리지 않음)에, 조회수·좋아요는 `data/youtube_videos.tsv`에 저장된다.
   - "Sign in to confirm you're not a bot"로 전부 실패하면: 네트워크 설정에 `www.youtube.com` 허용 여부를 확인하고, 그래도 안 되면 사용자에게 자막(스크립트 표시) 복사를 부탁한다.
4. **자막을 끝까지 읽는다** (자동 자막이라 오타가 많다. 맥락으로 이해).
5. **체크리스트 반영**: `아파트_셀프_사전점검_체크리스트.md`
   - 새 점검 항목은 `## 4.`의 해당 공간(`### …`) 목록 끝에 `- [ ] … *(영상)*` 형식으로 추가. 이미 있는 내용과 겹치면 넣지 않는다.
   - 준비물은 `## 3.`에 추가.
   - `## 9.` 표에 영상 행(제목 링크, 채널, 조회수, 좋아요, 핵심 한 줄)을 추가하고, 공통 강조점이 바뀌면 갱신.
   - 영상에서 확인하지 않은 내용을 영상 출처처럼 쓰지 않는다.
6. **엑셀 다시 만들기**: `python3 tools/make_xlsx.py`
   (점검표·준비물은 md에서, 참고영상 시트는 `data/youtube_videos.tsv`에서, 표준점검표는 `data/standard_form.json`에서 읽는다.)
   수식 확인이 필요하면 xlsx 스킬의 `recalc.py`를 **복사본**에 돌린다(원본에 돌리면 글꼴이 바뀜).
7. **커밋·푸시**하고, 바뀐 엑셀 파일을 사용자에게 보낸다. 무엇을 몇 개 추가했는지 한두 줄로 알린다.

## 참고
- 표준점검표(`data/standard_form.json`)는 포스코이앤씨가 배포한 국토교통부 「입주자 사전방문 표준점검표」를 옮긴 것.
- 사용자는 포스코이앤씨 **더샵** 단지에 입주 예정. 엑셀 "더샵 사전방문" 시트 참고.
